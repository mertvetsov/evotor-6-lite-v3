# Эвотор 6 lite — продуктовая страница (v3)

Лендинг акции «Касса за кассу» в формате продуктовой презентации: тёмная студия, 3D-терминал, который по скроллу поворачивается и «позирует» под каждый блок.

Стек: Vite, Three.js, GSAP + ScrollTrigger, Lenis, шрифт Onest.

```bash
npm install
npm run dev      # http://localhost:5174
npm run build    # сборка в dist/
```

## Как устроено

- `src/terminal.js` — 3D-терминал: загрузка GLB (meshopt), студийный свет, скриншоты интерфейса на экране, смена экранов.
- `src/main.js` — хореография: в вёрстке есть пустые зоны-слоты (`data-slot`), и для каждого ключевого кадра позиция и масштаб терминала вычисляются из реального размера слота. Поэтому касса не пересекается с текстом на любом размере окна.
- `src/styles.css` — тёмные секции прозрачные (через них виден 3D-слой), светлые непрозрачные и наезжают на него.
- `public/models/terminal.glb` — модель, `public/img/` — фото и текстуры экрана.

## Прототип

Визуальный прототип для согласования дизайна. Форма ничего не отправляет и не сохраняет, автозаполнение отключено, страница закрыта от индексации (`noindex`).

## GitHub Pages

Workflow `.github/workflows/pages.yml` собирает и публикует сайт. Пока Pages не включён, он ничего не публикует. Чтобы включить: Settings → Pages → Source: **GitHub Actions**, затем запустить workflow или сделать push в `main`.
